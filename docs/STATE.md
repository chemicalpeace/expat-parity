## Module Definition of Done

A Phase 3 module is done when all of these hold, in the same PR:

1. Differential tests against the C oracle are green (exhaustive where the
   domain allows, otherwise structured + random inputs), and a deliberately
   injected bug is shown to be caught.
2. Every touched entry point has been fuzzed differentially for >= 10 minutes
   with no finding; executions recorded in `docs/REPORT.md`; the minimised
   corpus is committed.
3. Module docs (rustdoc with an example), `docs/ARCHITECTURE.md` module map,
   decisions in `docs/DECISIONS.md`, divergences in `docs/DIVERGENCES.md`.
4. This file updated. CI green on the PR.

## Environment notes (for a fresh machine)

- Needs a C compiler (`build-essential` or Xcode CLT), rustup. Toolchain is
  pinned by `rust-toolchain.toml` (1.99.0); nightly for Miri/fuzz.
- `cargo install cargo-fuzz --locked` and `cargo-deny` (prebuilt release
  binaries work).
- Builds are faster with `CARGO_TARGET_DIR` on local disk.
